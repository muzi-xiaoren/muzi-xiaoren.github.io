你好，世界

博客上线啦，这是第一篇文章。

欢迎来到我的博客！这是用 Astro 搭建的个人站点，风格是一座按编号收藏文章的小档案馆。

怎么写新文章

在博客源码目录运行：

npm run new -- "文章标题"

文章会生成在 src/content/posts/ 下，用 Markdown 编写即可。写的时候运行 npm run dev，打开 http://localhost:4321 可以边写边看。

怎么发布

写完后把源码推到 GitHub：

git add -A
git commit -m "新增文章：文章标题"
git push

几分钟后刷新 https://muzi-xiaoren.github.io 就能看到更新。

接下来

  • 改 src/site.ts 里的站点标题、简介、社交链接
  • 把喜欢的图片放进 public/img/background/，它们会出现在首页的藏品区
  • 开始写自己的内容吧 🎉
